Factorio Circuit Tutorial

Learn how to build and use circuit networks in Factorio

Level 1: Basic Connections

Connect the constant combinator to the lamp using red wire. The lamp should light up when receiving a signal.

Available Components

Constant Combinator

Outputs constant signal values. Configure it to send specific signals with set values to the circuit network. Essential for providing input values to your circuits.

Arithmetic Combinator

Performs mathematical operations on signals. Can add, subtract, multiply, or divide signals. Takes two inputs and outputs the result.

Decider Combinator

Makes decisions based on signal conditions. Compares a signal value with a condition (>, <, =, etc.) and outputs a signal only when the condition is met.

Lamp

Visual indicator that lights up when receiving any signal. Useful for debugging circuits and showing when conditions are met.

Red Wire

Connects components to form a circuit network. Red wire signals are separate from green wire signals, allowing for multiple independent networks.

Green Wire

Connects components to form a circuit network. Green wire signals are separate from red wire signals, enabling complex multi-network designs.
