One-Rotor Enigma

A single Rotor I with the UKW-B reflector. Press keys to encipher. Each keypress advances the rotor before the current flows, so the substitution changes every letter. Strip the machine to bare wiring and add each component in turn to see what it contributes.

Experiments

  • Select Strip to bare wiring. Each key is wired straight to its own lamp, so the output equals the input.
  • Add only the reflector. It swaps 13 fixed letter pairs: a reciprocal substitution that never changes between keypresses.
  • Install the rotor with stepping off. The substitution is still fixed, but it is now a scrambled mapping instead of simple pairs.
  • Turn stepping on and type AAAAAA. The same input letter produces a different output each time because the rotor moves.
  • Reset to A, type a word, then reset again and type the output. The original word comes back. The reflector makes the machine its own inverse.
  • Repeat that with the reflector off. Decryption fails, because the current passes through the rotor only once and that mapping is not symmetric.
  • With the reflector on, check the table: no letter ever maps to itself. Codebreakers at Bletchley Park exploited this flaw.
  • Turn stepping off. The machine becomes a fixed substitution cipher, breakable by letter-frequency analysis.
  • Type 26 letters with stepping on. The cycle repeats after 26 keys. The real machine used three rotors to stretch this to 16,900.
