Experiments

  • Turn everything off. The keyboard is back to straight wires and the output equals the input.
  • Reset to A, type a word, then reset again and type the output. The original word comes back as long as the reflector is in.
  • Repeat that with the reflector off. Decryption fails, because the current crosses the rotor only once and that mapping is not symmetric.
  • With the reflector on, no letter ever maps to itself. Codebreakers at Bletchley Park exploited this flaw.
  • Type 26 letters with stepping on. The cycle repeats after 26 keys. The service machine used three rotors to stretch the period to 16,900.
